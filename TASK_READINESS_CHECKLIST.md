# Task Readiness Checklist

## Purpose

Bu kontrol listesi, bir görevin Coding Agent'a veya geliştiriciye verilmeden
önce uygulanmaya hazır olduğunu doğrulamak için kullanılır.

---

## 1. Business

- [ ] İş ihtiyacı açıklandı.
- [ ] Amaç tanımlandı.
- [ ] Beklenen çıktı açıklandı.

## 2. Scope

- [ ] Kapsam yazıldı.
- [ ] Kapsam dışı maddeler belirtildi.
- [ ] Bağımlılıklar tanımlandı.

## 3. Architecture

- [ ] Mimari etki değerlendirildi.
- [ ] Mevcut standartlarla uyum kontrol edildi.
- [ ] İnsan onayı alındı (gerekiyorsa).

## 4. Task Specification

- [ ] Task ID oluşturuldu.
- [ ] Açıklama tamamlandı.
- [ ] Değiştirilecek dosyalar listelendi.
- [ ] Acceptance Criteria yazıldı.

## 5. Testing

- [ ] Test senaryoları tanımlandı.
- [ ] Başarı kriterleri belirlendi.
- [ ] Regresyon etkisi değerlendirildi.

## 6. Documentation

- [ ] Güncellenecek dokümanlar belirlendi.
- [ ] Teknik notlar eklendi.

## 7. Risk Assessment

- [ ] Güvenlik etkisi incelendi.
- [ ] Performans etkisi incelendi.
- [ ] Rollback planı hazırlandı.

## Definition of Ready

Bir görev aşağıdaki koşulların tamamını sağlıyorsa "Ready" kabul edilir:

- Specification eksiksizdir.
- Acceptance Criteria yazılmıştır.
- Gerekli onaylar alınmıştır.
- Test planı hazırlanmıştır.
- Risk analizi tamamlanmıştır.

END OF DOCUMENT
