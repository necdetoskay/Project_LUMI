# Media Moderation

Her görsel ve ses isteği üretimden önce moderation sürecinden geçer.

Kontroller:

- Child safety
- Graphic violence
- Sexual content
- Self-harm
- Hate symbols
- Age suitability
- Purpose suitability

Moderation başarısız olursa:

- Provider çağrılmaz
- Maliyet oluşmaz
- Request `moderation_failed` olur
- Parent dashboard'a anlamlı özet düşer
