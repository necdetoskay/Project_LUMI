# Hybrid Retrieval

LUMI memory retrieval tek başına embedding'e bağlı değildir.

Hybrid yaklaşım:

1. World scope filter
2. Memory type filter
3. Subject graph relevance
4. Semantic similarity
5. Keyword fallback
6. Recency decay
7. Importance
8. Emotional salience
9. Consequence weighting
10. Context token budget

Embedding provider çalışmazsa retrieval keyword ve graph tabanlı devam eder.

Bu nedenle embedding sistemi optional enhancement olarak değerlendirilir.
