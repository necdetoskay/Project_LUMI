# NPC Emergent Interaction Rules

## Proaktif davranış

NPC etkileşim oluşturmak için kullanıcının doğrudan komutunu beklemez.

Etkileşim türleri:

- Rumor
- Gift
- Warning
- Invitation
- Quest seed
- Social visit
- Information share

## Kaynak sinyalleri

- Aktif NPC hedefleri
- Sahip olunan paylaşılabilir eşyalar
- Bilinen söylentiler
- Çözülmemiş dünya olayları
- İlişki vektörü
- Yakınlık
- Zaman hassasiyeti
- Novelty skoru

## Hedef seçimi

Hedef seçimi yalnızca en yakın karaktere göre yapılmaz.

Kullanılan sinyaller:

- Relationship strength
- Proximity
- Role compatibility
- Recent interaction penalty

## Kullanıcıya teslim

Opportunity önce inbox'a düşer.

Kullanıcı:

- Kabul edebilir
- Reddedebilir
- Daha sonra inceleyebilir
- Süresi dolmadan story hook'a dönüştürebilir
