# Reporting Rules

Parent report aşağıdaki alanları içerebilir:

- Tarih aralığı
- Child profile
- Dashboard summary
- Opportunity metrics
- Cost metrics
- Timeline
- Safety summary
- Simulation summary

Rapor formatları:

- JSON
- CSV
- Daha sonraki paketlerde PDF

Çocuk konuşmaları veya hassas yanıtlar ebeveyn raporuna ham biçimde eklenmemelidir.
