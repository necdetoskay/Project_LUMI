# Parent Onboarding UI Flow

## 1. Dashboard

Kullanıcı onboarding başlangıç kartını görür.

## 2. Household

- Aile adı
- Slug
- Idempotent create
- Validation error

## 3. Child

- Çocuk adı
- Doğum yılı
- Household access

## 4. World

İlk sürümde güvenli başlangıç template'i seçilir:

- LUMI Evreni
- Işık Adası
- Yeşil Vadi
- Başlangıç Evi

Daha sonra template seçimi ve özgün dünya oluşturma eklenecektir.

## 5. Avatar

- Karakter adı
- Child profile bağlantısı
- Starting location
- Personal inventory

## 6. Summary

Oluşturulan domain kimlikleri ve durum gösterilir.

## 7. Inventory

Boş durum ekranı gösterilir ve kullanıcı ilk hikâyeye yönlendirilir.
