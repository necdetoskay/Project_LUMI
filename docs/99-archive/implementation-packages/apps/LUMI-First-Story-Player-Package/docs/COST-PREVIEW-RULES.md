# Cost Preview Rules

- Maliyet üretim başlamadan gösterilir.
- Para birimi Türk lirasıdır.
- Tahmin ve gerçek maliyet ayrı saklanır.
- Görsel sayısı toplamı doğrudan etkiler.
- TTS kapalıysa ses maliyeti sıfırdır.
- Provider pricing değişiklikleri registry üzerinden alınmalıdır.
- UI sabit fiyatı tek otorite olarak kabul etmemelidir.
- Gerçek maliyet generation attempt tamamlandığında cost_records tablosuna yazılır.
