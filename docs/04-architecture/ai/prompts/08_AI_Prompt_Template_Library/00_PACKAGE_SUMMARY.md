# LUMI Paket 08 — AI Prompt & Template Library

## Amaç
Hikâye, NPC, diyalog, görsel, TTS ve güvenlik üretimlerini sürüm kontrollü, test edilebilir prompt şablonlarıyla yönetmek.

## Temel Kararlar
- Promptlar kod içine dağınık gömülmeyecek.
- Her prompt benzersiz kimlik ve versiyon taşıyacak.
- System, policy, context ve task katmanları ayrılacak.
- Structured output zorunlu tutulacak.
- Yaş grubu, ton, dil ve güvenlik profili parametreleştirilecek.
- Prompt değişiklikleri eval testinden geçecek.
