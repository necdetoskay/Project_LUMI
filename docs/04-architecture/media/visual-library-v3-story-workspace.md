# Visual Library v3 — Story Workspace Boundary

The primary Visual Library navigation follows:

`Visual Library → Character → Character stories → Story Visual Workspace`

Asset-type navigation (`Characters`, `Items`, `Environments`, `Scenes`) belongs inside one story workspace rather than at the top level of the library.

Character story cards are backed by real story sessions and link to `/app/assets/stories/[sessionId]`.

The current workspace shell intentionally shows manifest-dependent counts and story visual style as pending until Story Visual Manifest / Story Visual Asset Set binding is completed in the next delivery slice. This prevents fabricated readiness numbers while establishing the final navigation contract.
