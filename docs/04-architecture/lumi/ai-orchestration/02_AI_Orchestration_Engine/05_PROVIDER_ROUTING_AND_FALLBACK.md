# Provider Routing ve Fallback

Router seçim kriterleri:
- görev tipi
- kalite gereksinimi
- gecikme
- maliyet
- sağlayıcı sağlığı
- yaş uygunluğu desteği

Örnek fallback:
1. Birincil LLM
2. Daha ekonomik yedek model
3. Son başarılı template tabanlı güvenli üretim

Görsel ve TTS için ayrı provider zincirleri kullanılır.
