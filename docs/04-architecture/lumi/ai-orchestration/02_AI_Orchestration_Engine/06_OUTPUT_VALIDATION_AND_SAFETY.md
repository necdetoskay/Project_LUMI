# Output Validation ve Güvenlik

- JSON schema doğrulaması
- Yasaklı alan/eksik alan kontrolü
- Yaş seviyesine göre dil kontrolü
- Şiddet, korku ve uygunsuz içerik filtresi

Geçersiz cevap otomatik olarak kullanıcıya gösterilmez; repair prompt veya fallback uygulanır.
