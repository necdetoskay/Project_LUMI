# Engineering

Kod üretimi, kalite doğrulaması, test, gözlemlenebilirlik, DevOps ve
dokümantasyon uygulamalarını içerir.

- [`quality/`](quality/) — test ve observability
- [`devops/`](devops/) — çalışma ortamı, CI/CD ve operasyon
- [`documentation/`](documentation/) — dokümantasyon mühendisliği kaynakları

Bağlayıcı genel mühendislik standartları `docs/eos/` altındadır.
