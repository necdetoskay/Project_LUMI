# Specifications

Bu bölüm sprintten bağımsız, uygulanabilir ve test edilebilir LUMI
specification'ları için ayrılmıştır.

Bir specification:

- kapsam ve kapsam dışını,
- önkoşulları,
- işlevsel ve teknik gereksinimleri,
- kabul kriterlerini,
- test planını,
- güvenlik ve gözlemlenebilirlik şartlarını

açıkça tanımlamalıdır.

Sprint özelindeki specification'lar `07-delivery/` altında kalır.
