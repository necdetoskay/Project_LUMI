# Image Prompt Templates

## Amaç
Karakter ve dünya görsel sürekliliğini korumak.

## Prompt Bölümleri
- scene intent
- character identity anchors
- environment
- action
- emotion
- composition
- age-safe constraints
- negative constraints
- output dimensions

## Süreklilik
Karakter için değişmeyen kimlik alanları:
- yüz
- saç
- kıyafet temel formu
- renk paleti
- sembolik aksesuar

## Maliyet
Önizleme, küçük ikon ve tam sayfa görseli için ayrı kalite profilleri kullanılır.
