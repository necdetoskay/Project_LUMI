# Story Prompt Templates

## Story Continuation
Girdi:
- child age band
- current location
- active characters
- recent choices
- relevant inventory
- unresolved hooks
- emotional state
- educational goal

Çıktı:
- narration
- dialogue
- consequences
- next choices
- state mutations
- safety tags

## Kural
Hikâye çocuğa sürekli başarı vermemeli; anlaşılır, güvenli ve yaşa uygun belirsizlik taşımalıdır.
