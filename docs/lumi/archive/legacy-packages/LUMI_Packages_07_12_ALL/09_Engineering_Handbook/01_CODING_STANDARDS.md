# Coding Standards

- TypeScript strict mode zorunlu.
- `any` yalnızca gerekçeli ve izole kullanımda.
- Public fonksiyonlar explicit return type taşır.
- Domain katmanı framework bağımsızdır.
- Pure function tercih edilir.
- Magic number/string kullanılmaz.
- Fonksiyonlar tek sorumluluk taşır.
- Validation sınır katmanında ve domain invariant düzeyinde uygulanır.
