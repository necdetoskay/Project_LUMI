# Character Roles and Archetypes

Version: Draft v1.0

Status: Design Archive

---

# Purpose

Roles describe what characters contribute to society.

Archetypes describe how they naturally behave.

Neither permanently defines the individual.

---

# Roles

Examples include:

- Farmer
- Teacher
- Sailor
- Blacksmith
- Baker
- Explorer
- Musician
- Healer
- Storyteller
- Shepherd
- Merchant

Roles influence routines, knowledge and relationships.

---

# Archetypes

Examples include:

- Protector
- Dreamer
- Inventor
- Caregiver
- Wanderer
- Mentor
- Guardian
- Builder
- Scholar
- Observer

Archetypes influence emotional tendencies rather than occupations.

---

# Multiple Roles

One character may hold multiple roles.

Example:

Teacher

+

Mother

+

Village Historian

Each contributes differently to daily behavior.

---

# Evolution

Roles change naturally.

A child may become an apprentice.

Later a craftsperson.

Eventually a respected master.

---

# Design Goal

Represent social diversity without restricting character growth.
