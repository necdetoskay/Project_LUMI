# Shared, Collective and Generational Memory

Version: Draft v1.0

Status: Design Archive

---

# Purpose

Not every memory belongs to a single individual.

Communities, families and cultures also remember.

Collective memory gives continuity to the Living Universe beyond individual lives.

---

# Collective Memory

Groups remember together.

Examples include:

- Great storms
- Harvest celebrations
- Wars
- Legendary heroes
- Village founders
- Sacred places

These memories shape culture.

---

# Generational Memory

Knowledge passes naturally between generations.

Examples

Grandparents teach traditions.

Parents tell family stories.

Teachers preserve history.

Storytellers keep legends alive.

---

# Living Tradition

Traditions are repeated memories.

The original event may disappear while the tradition survives.

Example

A yearly lantern festival may continue long after everyone has forgotten why it first began.

---

# Memory Evolution

Collective memories change.

Some details disappear.

Others become symbolic.

History slowly transforms into legend.

---

# Design Goal

Allow civilizations to remember even after individuals are gone.
