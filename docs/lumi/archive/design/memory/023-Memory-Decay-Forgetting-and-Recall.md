# Memory Decay, Forgetting and Recall

Version: Draft v1.0

Status: Design Archive

---

# Purpose

Forgetting is as important as remembering.

A believable mind gradually lets unimportant experiences fade.

---

# Memory Decay

Every memory slowly loses accessibility.

Important memories decay more slowly.

Repeated recall strengthens them again.

---

# Forgetting

Minor events eventually disappear.

Examples

Routine walks

Ordinary conversations

Daily chores

Meaningful moments remain much longer.

---

# Recall Triggers

Memories may be triggered by:

People

Places

Objects

Music

Weather

Smells

Words

Festivals

Dreams

---

# Memory Distortion

Memories are not perfect recordings.

Over time:

details fade

emotions change

interpretations evolve

Two characters may sincerely remember the same event differently.

---

# Reinforcement

Frequently remembered events become increasingly stable.

Shared storytelling also strengthens memories.

Communities preserve important events through repetition.

---

# Emotional Recall

Strong emotions immediately increase recall probability.

A familiar melody may instantly revive childhood memories.

---

# Design Goal

Remembering and forgetting should both contribute to believable long-term character development.
