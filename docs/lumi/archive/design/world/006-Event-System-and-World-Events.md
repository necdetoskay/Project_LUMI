# Event System and World Events

Version: Draft v1.0

Status: Design Archive

---

# Purpose

Everything meaningful in LUMI is represented as an event.

Events connect every system together.

---

# Examples

- a child gets lost
- heavy rain begins
- bridge collapses
- baby fox is born
- harvest festival starts
- tree falls
- merchant arrives
- old king dies
- eclipse occurs

# Event Importance

Not every event deserves attention.

Importance depends on:

- emotional impact
- affected population
- historical relevance
- proximity
- relationship strength
- narrative potential

---

# Cascading Events

One event may create dozens of others.

Example

Storm

↓

Bridge destroyed

↓

Merchant delayed

↓

Medicine unavailable

↓

Villager becomes sick

↓

Child discovers abandoned road

---

# Event Expiration

Minor events disappear naturally.

Major events become part of history.

---

# Design Goal

The world should feel connected through chains of consequences.
