# Purpose

The World Memory Graph stores how people, places, objects and events are connected through history.

It is the world's long-term memory.

# Living Connections

Connections are never static.

They strengthen.

Fade.

Merge.

Split.

Disappear.

---

# Historical Importance

Every node contains significance.

Small events slowly lose importance.

Major events remain for generations.

---

# Emotional Memory

The graph stores more than facts.

It stores emotional associations.

A lake may represent:

- safety
- fear
- hope
- loss

depending on each character's experiences.

---

# Narrative Usage

The Story Engine searches the graph for meaningful relationships rather than random story ideas.

---

# Design Goal

The universe should remember relationships instead of isolated facts.
