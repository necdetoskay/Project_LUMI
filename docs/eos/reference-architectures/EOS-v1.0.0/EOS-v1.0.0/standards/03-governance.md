# 03 — Governance Standard

**Document ID:** EOS-STD-003  
**Version:** 1.0.0  
**Status:** Approved

## Purpose

Manage decisions, ownership, exceptions, and authoritative sources.

## Principles

- Decisions are explicit.
- Authority is role-based.
- Exceptions are visible.
- Governance should enable delivery, not create bureaucracy.

## Required Practices

- Record strategic and architectural decisions.
- Assign owners to governed documents.
- Use this precedence:
  Constitution → Standards → Templates → Project Documents → Generated Content.
- Route new ideas through backlog and planning.
- Document exceptions with reason, risk, owner, and expiry.

## Decision Types

- Strategic
- Tactical
- Operational
- Emergency

## Authorities

- Product owns value, priority, and scope.
- Engineering owns technical implementation and quality.
- AI agents operate within assigned tasks and standards.
- Humans approve final decisions.

## Anti-Patterns

- Hidden decisions
- Undefined ownership
- Permanent undocumented exceptions
- AI-generated facts treated as verified truth

## Deliverables

- Decision records
- Ownership records
- Exception records
- Approval history

## Exit Criteria

Governance is effective when decisions are traceable and unresolved authority conflicts do not block execution.
