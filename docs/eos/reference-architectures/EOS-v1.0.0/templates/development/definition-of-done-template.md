# Definition of Done

## Product

- [ ] Acceptance criteria satisfied
- [ ] Product owner review complete

## Code

- [ ] Implementation complete
- [ ] Formatting and linting pass
- [ ] Type checks pass
- [ ] No debug code remains

## Testing

- [ ] Unit tests pass
- [ ] Integration tests pass
- [ ] Required E2E tests pass
- [ ] Regression risks checked

## Security

- [ ] Inputs validated
- [ ] Authorization checked
- [ ] No secret committed
- [ ] Security findings resolved

## Documentation

- [ ] Technical documentation updated
- [ ] User or operations documentation updated
- [ ] Changelog updated when required

## Delivery

- [ ] Review approved
- [ ] Build succeeds
- [ ] Required evidence attached
