# 07 — Coding Standard

**Document ID:** EOS-STD-007  
**Version:** 1.0.0  
**Status:** Approved

## Purpose

Produce readable, maintainable, testable, and consistent code.

## Principles

- Readability
- Simplicity
- Consistency
- Single Responsibility
- Explicit behavior
- Testability

## Required Practices

- Use meaningful names.
- Keep functions and modules focused.
- Validate external inputs.
- Handle errors deliberately.
- Remove debug artifacts.
- Apply formatting, linting, type checking, and review.
- Add or update tests for changed behavior.
- Document non-obvious decisions.

## Anti-Patterns

- Long multi-purpose methods
- Copy-paste implementation
- Hidden side effects
- Silent error swallowing
- Premature abstraction
- Comments that compensate for unclear code

## Exit Criteria

Code is complete when it passes automated checks, tests, review, and related documentation updates.
