# Code Review Playbook

## Purpose

Bu playbook, kaynak kodu değişikliklerinin kalite, güvenlik ve sürdürülebilirlik
açısından tutarlı biçimde incelenmesini tanımlar.

## Phase 1 - Review Preparation

- Task Specification incelenir.
- İlgili gereksinimler doğrulanır.
- Test sonuçları gözden geçirilir.
- Değişiklik kapsamı anlaşılır.

## Phase 2 - Functional Review

- Acceptance Criteria karşılanıyor mu?
- İş kuralları doğru uygulanmış mı?
- Beklenmeyen davranış var mı?

## Phase 3 - Technical Review

- Kod standartlara uygun mu?
- Mimari korunmuş mu?
- Performans etkisi değerlendirildi mi?
- Güvenlik açıkları bulunuyor mu?

## Phase 4 - Validation

- Test kapsamı yeterli mi?
- Dokümantasyon güncel mi?
- Hata senaryoları ele alınmış mı?

## Review Outcomes

- Approved
- Approved with Minor Changes
- Changes Requested
- Rejected

## Reviewer Responsibilities

- Yapıcı geri bildirim verir.
- Kapsam dışı talepler oluşturmaz.
- Kritik riskleri açıkça raporlar.

## Exit Criteria

- [ ] Review tamamlandı
- [ ] Kritik bulgu yok
- [ ] Gerekli düzeltmeler yapıldı
- [ ] Testler doğrulandı
- [ ] Onay verildi

END OF PLAYBOOK
