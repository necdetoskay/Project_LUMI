# Paket 03 — API Design

## Amaç
Web, mobil ve gelecekteki istemcilerin kullanabileceği güvenli, versionlanabilir ve gözlemlenebilir API sözleşmesini belirlemek.

## Kararlar
- REST ana protokol
- SSE hikâye üretim ilerlemesi için
- WebSocket yalnızca gerçek zamanlı çift yönlü ihtiyaç oluşursa
- `/api/v1` versionlama
- Problem Details tabanlı hata modeli
