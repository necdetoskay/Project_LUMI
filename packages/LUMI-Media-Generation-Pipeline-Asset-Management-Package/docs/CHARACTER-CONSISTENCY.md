# Character Consistency

Karakter tutarlılığı yalnızca isimle sağlanmaz.

Consistency metadata:

- Character ID
- Age band
- Species
- Hair
- Eyes
- Clothing signature
- Color palette hints
- Distinguishing features
- Style tags
- Reference asset IDs
- Seed

Her yeni üretimde bu metadata prompt'a ve provider isteğine eklenir.

Reference image desteği olmayan modellerde metinsel consistency profili kullanılır.
