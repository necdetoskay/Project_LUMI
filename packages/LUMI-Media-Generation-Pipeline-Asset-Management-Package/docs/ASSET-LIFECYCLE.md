## Request

Media request üretim niyetini temsil eder.

## Asset

Media asset gerçek depolanan çıktıyı temsil eder.

## Attachment

Story media attachment varlığı hikâye veya node ile bağlar.

Aynı asset:

- Story page
- Thumbnail
- Avatar
- World map

gibi farklı rollerde kullanılabilir.
