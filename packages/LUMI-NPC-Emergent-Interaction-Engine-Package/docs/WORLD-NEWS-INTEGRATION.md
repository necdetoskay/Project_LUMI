# World News Integration

Aşağıdaki etkileşimler world news kaydı oluşturabilir:

- Rumor
- Warning
- Invitation
- Quest seed

Amaç:

- Dünyanın kullanıcıdan bağımsız yaşadığını göstermek
- Hikâye dışında da gelişmeleri görünür kılmak
- Kullanıcıya birden fazla macera seçeneği sunmak

Her world news kaydı:

- Kaynak interaction ID
- Başlık
- Özet
- Visibility
- Expiry

alanlarını taşır.
