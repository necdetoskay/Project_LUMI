# Novelty, Cooldown and Expiry

## Novelty

Aynı NPC sürekli aynı tür etkileşim üretmemelidir.

Novelty düşüren sinyaller:

- Son 7 günde aynı tür etkileşim sayısı
- Son 7 günde aynı kaynaktan gelen etkileşim sayısı
- Son 30 günde benzer özet sayısı

## Cooldown

Ayrı cooldown alanları:

- Source NPC cooldown
- Target NPC cooldown
- Source-target pair cooldown

## Expiry

Zamana duyarlı fırsatlar sonsuza kadar açık kalmaz.

Örnek:

- Warning: kısa süre
- Invitation: orta süre
- Quest seed: daha uzun süre
- Gift: kalıcı veya uzun süreli olabilir
