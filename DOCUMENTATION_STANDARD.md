# Documentation Standard

## Purpose

Bu standart, proje boyunca üretilen tüm teknik ve iş dokümantasyonunun
tutarlı, güncel ve sürdürülebilir olmasını sağlar.

## Core Principles

- Dokümantasyon kodun tamamlayıcısıdır.
- Her önemli mimari karar belgelenmelidir.
- Belgeler sürüm bilgisi içermelidir.
- Eski bilgiler güncellenmeli veya arşivlenmelidir.

## Required Documents

- README
- Architecture
- API Documentation
- Database Documentation
- Deployment Guide
- Operations Guide
- ADR (Architecture Decision Record)
- Release Notes
- Changelog

## Documentation Rules

- Açık ve anlaşılır dil kullanılmalıdır.
- Gereksiz tekrar yapılmamalıdır.
- Diyagramlar gerektiğinde güncellenmelidir.
- Dosya adları standartlara uygun olmalıdır.

## Versioning

Her dokümanda en az:
- Version
- Status
- Last Updated
- Owner (varsa)

alanları bulunmalıdır.

## AI Coding Agent Responsibilities

- Yeni özellikler için gerekli dokümantasyonu oluşturur.
- Mevcut belgeleri değişikliklere göre günceller.
- Eksik dokümantasyonu raporlar.

## Completion Checklist

- [ ] İlgili belgeler güncellendi
- [ ] Sürüm bilgisi eklendi
- [ ] Eski bilgiler kaldırıldı
- [ ] Doküman doğruluğu kontrol edildi

END OF DOCUMENT
