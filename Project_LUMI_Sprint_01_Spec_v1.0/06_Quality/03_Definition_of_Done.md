# Sprint 01 Definition of Done

A backlog item is done when:

- implementation satisfies its acceptance criteria;
- external input is validated;
- relevant tests exist and pass;
- logs and errors follow conventions;
- no secret or personal data is introduced;
- documentation is updated;
- code review is complete;
- lint and type-check pass.

The sprint is done when:

1. All mandatory backlog items are complete.
2. All acceptance criteria pass.
3. Production build succeeds.
4. CI succeeds from a clean checkout.
5. Database migration and seed succeed on an empty database.
6. The readiness endpoint fails safely when PostgreSQL is stopped.
7. Protected application routes enforce the selected session boundary.
8. No critical or high-severity known defect remains.
9. No out-of-scope living-universe feature has been partially embedded.
10. A completion report records versions, commands, evidence and remaining issues.
