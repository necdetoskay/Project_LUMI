# Metrics ve SLO

Ana metrikler:
- API latency p50/p95/p99
- Error rate
- Story generation success rate
- Media generation latency
- Queue wait time
- DB connection usage
- Cache hit ratio
- Cost per story

Örnek SLO: Story text generation isteklerinin %95’i kabul edilebilir süre içinde tamamlanmalıdır.
