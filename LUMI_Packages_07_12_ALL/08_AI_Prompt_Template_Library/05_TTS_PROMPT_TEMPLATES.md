# TTS Prompt Templates

## Metadata
- narrator voice
- speaking rate
- emotion
- pause markers
- pronunciation hints
- ambient cues

## İşaretler
Metin içinde sağlayıcıya özel ham etiket yerine normalize edilmiş sahne yönergeleri tutulur.

Örnek:
```json
{
  "text": "Ormanın içinden yumuşak bir rüzgâr geçti.",
  "delivery": "warm_curious",
  "pauseAfterMs": 400,
  "sfxCue": "forest_breeze"
}
```
