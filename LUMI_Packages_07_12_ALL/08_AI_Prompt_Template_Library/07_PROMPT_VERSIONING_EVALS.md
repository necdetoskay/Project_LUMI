# Prompt Versioning & Evaluations

## Değişiklik Akışı
Draft → Review → Eval → Approved → Active → Deprecated

## Eval Boyutları
- yaş uygunluğu
- süreklilik
- yaratıcılık
- güvenlik
- format geçerliliği
- maliyet
- latency
- tekrar oranı

## A/B Test
Çocuk güvenliği alanlarında A/B test yapılmaz; yalnızca onaylı güvenli sürümler karşılaştırılır.
