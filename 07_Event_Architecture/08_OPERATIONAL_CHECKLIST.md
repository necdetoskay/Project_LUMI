# Event Architecture Operational Checklist

- [ ] Event naming standardına uyuldu
- [ ] Event version belirtildi
- [ ] Correlation ve causation id üretildi
- [ ] Payload hassas veri içermiyor
- [ ] Consumer idempotent
- [ ] Retry politikası tanımlı
- [ ] Dead-letter davranışı tanımlı
- [ ] Outbox transaction içinde yazılıyor
- [ ] Metrics ve tracing etkin
- [ ] Replay güvenlik kontrolleri mevcut
