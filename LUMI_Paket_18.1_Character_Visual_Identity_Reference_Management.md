# Project LUMI -- Paket 18.1

# Character Visual Identity & Reference Management

## Amaç

Karakterlerin tüm hikâyelerde, görsellerde ve gelecekte üretilecek
içeriklerde aynı kimliği korumasını sağlayan merkezi görsel referans
sistemini tanımlamak.

## Temel İlkeler

-   Her karakter benzersiz bir Visual ID alır.
-   Görsel kimlik sürümlenir.
-   Referans görseller merkezi olarak yönetilir.
-   Stil değişse bile karakter tanınabilir kalır.

## Visual Identity Profili

Her karakter için:

-   Character ID
-   Visual Version
-   Yaş Aralığı
-   Boy / Vücut Yapısı
-   Yüz Hatları
-   Saç Modeli
-   Saç Rengi
-   Göz Rengi
-   Ten Rengi
-   Kıyafet Profili
-   Aksesuarlar
-   Ayırt Edici Özellikler

## Referans Görseller

Saklanacak referanslar:

-   Ön görünüş
-   Yan görünüş
-   Arka görünüş
-   Yakın portre
-   Tam vücut
-   Farklı mimikler
-   Farklı pozlar

## Varyasyon Kuralları

Değişebilir: - Yüz ifadesi - Poz - Işık - Kamera açısı - Ortam

Korunmalıdır: - Kimlik - Oranlar - Ana renk paleti - Ayırt edici
detaylar

## Sürüm Yönetimi

Her değişiklik: - Yeni Visual Version oluşturur. - Eski sürümler
arşivlenir. - Geri alma desteklenir.

## Doğrulama

Kontroller: - Kimlik tutarlılığı - Renk uyumu - Referans eşleşmesi -
Stil uygunluğu

## Test Senaryoları

-   Aynı karakter farklı hikâyelerde
-   Farklı sanat stilleri
-   Yaş ilerlemesi
-   Kıyafet değişimi
-   Referans güncellemesi

## Çıktılar

-   Character Visual Profile
-   Reference Pack
-   Visual Manifest
-   Consistency Report
