# LUMI — First Story Creation + Story Player Foundation

Bu paket, Project LUMI'nin ilk oynanabilir hikâye vertical slice'ını kurar.

## Kapsam

- Yeni hikâye oluşturma ekranı
- Hikâye türü seçimi
- Katılımcı seçimi
- Başlangıç envanter eşyası seçimi
- AI generation request
- Tahmini maliyet önizleme
- Story session oluşturma
- Narrative node player
- Choice cards
- Karar kaydı
- Story completion
- Education questions
- Reflection screen
- Story history
- Playwright story flow testleri

## İlk uçtan uca akış

```text
New Story
→ Story Type
→ Participants
→ Inventory Item
→ Cost Preview
→ Generate Story
→ Start Session
→ Read Node
→ Make Choice
→ Record Decision
→ Complete Story
→ Answer Questions
→ Reflection
→ Story History
```

## Ön koşullar

- Parent Onboarding UI Package
- API + Auth Foundation Package
- Story + Education Data Package
- AI + Audit + System Package
