# LUMI — Parent Dashboard + World Timeline + Analytics

Bu paket, Project LUMI'nin ebeveyn görünümünü, yaşayan dünya zaman çizelgesini ve operasyonel/ürün analitiğini kurar.

## Kapsam

- Parent dashboard summary
- Child activity overview
- World timeline
- Story activity metrics
- Opportunity conversion metrics
- Cost overview
- Safety review summary
- Simulation activity summary
- Memory growth summary
- Parent action center
- Date filters
- Export-ready reports
- Playwright tests

Story / Simulation / Memory / Opportunity / Cost / Safety Events
