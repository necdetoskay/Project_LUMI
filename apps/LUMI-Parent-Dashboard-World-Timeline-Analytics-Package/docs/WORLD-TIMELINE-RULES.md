# World Timeline Rules

Timeline kronolojik ve açıklanabilir olmalıdır.

Gösterilebilecek kayıtlar:

- Story oluşturma ve tamamlama
- Önemli kararlar
- NPC fırsatları
- World news
- Simulation events
- Memory kayıtları
- Safety kararları
- Cost records

Timeline tüm düşük seviyeli teknik olayları göstermemelidir.

Yalnızca ebeveyn için anlamlı olaylar sunulur.
