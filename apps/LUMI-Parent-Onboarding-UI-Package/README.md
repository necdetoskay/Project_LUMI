# LUMI — Parent Onboarding UI + First Application Vertical Slice

Bu paket, Project LUMI'nin ebeveyn onboarding akışını uçtan uca kurar.

## Kapsam

- Login ekranı
- Parent dashboard shell
- Household oluşturma
- Child profile oluşturma
- World creation wizard
- Avatar creation wizard
- Foundation summary screen
- Empty inventory screen
- API client
- Zod + React Hook Form validation
- Loading, success ve error durumları
- Playwright onboarding testleri

## Teknoloji

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Shadcn UI uyumlu bileşen yapısı
- React Hook Form
- Zod
- Zustand

## İlk kullanıcı akışı

```text
Login
→ Household
→ Child Profile
→ World
→ Avatar
→ Summary
→ Inventory
```

- Data Layer Stabilization Package
