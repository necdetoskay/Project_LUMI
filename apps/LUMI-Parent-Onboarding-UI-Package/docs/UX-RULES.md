# UX Rules

- Her ekranda tek ana eylem bulunmalıdır.
- Kullanıcı tamamlanmış adımlarını görmelidir.
- Teknik hata detayları yerine anlaşılır mesaj verilmelidir.
- Request ID destek amaçlı gösterilebilir.
- Form verileri sayfa geçişlerinde korunmalıdır.
- Mobil ekranlar birinci sınıf desteklenmelidir.
- Çocukla ilgili ayarlar ebeveyn arayüzünde açık ve sade tutulmalıdır.
- Varsayılan güvenlik seviyesi strict olmalıdır.
