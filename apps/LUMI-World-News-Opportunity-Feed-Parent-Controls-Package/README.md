# LUMI — World News + Opportunity Feed + Parent Controls

Bu paket, Project LUMI'nin yaşayan dünya gelişmelerini kullanıcıya sunan haber akışı, fırsat kutusu ve ebeveyn kontrol katmanını kurar.

## Kapsam

- World news feed
- Opportunity inbox UI
- Accept / decline / snooze
- Story hook preview
- Parent approval rules
- Child-safe visibility rules
- Notification preferences
- Expiry indicators
- Priority sorting
- Feed filtering
- Read/unread states
- Opportunity analytics
- Playwright tests

## Ana akış

```text
NPC Interaction / Simulation Event
→ World News Record
→ Visibility Evaluation
→ Parent Approval Check
→ Feed Prioritization
→ Opportunity Inbox Delivery
→ Accept / Decline / Snooze
→ Story Hook Preview
→ Start Story
```
