# Opportunity Analytics

Ölçülebilecek olaylar:

- Viewed
- Accepted
- Declined
- Snoozed
- Expired
- Story started

Temel metrikler:

- Acceptance rate
- Decline rate
- Snooze rate
- Expiry rate
- Story conversion rate
- Ortalama karar süresi
- Interaction type bazında performans

Analytics çocuk davranışını manipüle etmek için kullanılmamalıdır.
