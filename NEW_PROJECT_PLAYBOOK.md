# New Project Playbook

## Purpose

Bu playbook, yeni bir yazılım projesinin fikir aşamasından ilk geliştirme sprintine
kadar izlenecek standart süreci tanımlar.

## Phase 1 - Project Initiation

- Proje vizyonunu tanımla
- Paydaşları belirle
- Başarı kriterlerini oluştur
- Kapsamı netleştir

## Phase 2 - Discovery

- İş gereksinimlerini topla
- Risk analizi yap
- Öncelikleri belirle
- Varsayımları doğrula

## Phase 3 - Architecture

- Teknoloji seçimi
- Mimari kararlar (ADR)
- Veri modeli tasarımı
- Güvenlik yaklaşımı

## Phase 4 - Planning

- Product Backlog oluştur
- Sprint planlarını hazırla
- Task Specification belgelerini yaz
- Kabul kriterlerini belirle

## Phase 5 - Design Freeze

- Mimariyi onayla
- Standartları doğrula
- Dokümantasyonu tamamla
- Geliştirme başlangıcını onayla

## Exit Criteria

- [ ] Gereksinimler onaylandı
- [ ] ADR'ler tamamlandı
- [ ] Sprint planı hazır
- [ ] Riskler değerlendirildi
- [ ] Geliştirmeye hazır

END OF PLAYBOOK
